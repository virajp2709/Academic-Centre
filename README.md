# Academic Command Center — GitHub Pages

A professional, browser-based B.Tech AI & Data Science academic tracker.

## Included

- First Year → Semester I and Semester II preloaded from the supplied university scheme
- Second, Third and Fourth Year structure ready for future data
- Add/edit subjects
- Add chapters/units
- Chapter status: Not Started / In Progress / Completed
- Notes status
- Revision status
- Chapter weightage %
- Priority
- Semester progress
- Revision queue
- JSON export/import backup
- Browser local storage
- Responsive desktop/mobile UI

## GitHub Pages

This is a static site, so no server is required.

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and open the generated Pages URL.

## Important privacy note

A GitHub Pages site is not automatically private just because its source repository is private. GitHub documents that private publication/access control for Pages is an Enterprise Cloud organization feature. On a normal personal GitHub account, treat the published site as public unless your GitHub plan/org configuration explicitly provides private Pages access.

The tracker stores study data in the browser's local storage. It does not upload your progress to GitHub. Use Export data regularly for backups.

## Adding official chapters

The screenshots supplied with this version contain the semester subject structure, not the individual chapter/unit lists. The app therefore does **not invent chapter names**. Open a subject and add the official chapters from your syllabus.
